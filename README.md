# NHL-statistics-project
A statistics research project that answers the question: Is there a significant home-ice advantage in the National Hockey League?

All of the project's findings are in the summarized poster. The other files contain the datasets I used and the R code I used to produce visualizations and run tests.

Directions to run R code in the R file: this is an old project, so Claude helped me to connect the data to the R file to run more smoothly.
